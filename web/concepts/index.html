The new explorer covers 19 signed-out and signed-in views, with light and dark themes and loading, error and empty states. The shelf-only studies below are earlier references.

Four directions for the same shelf, with the same data and actions as web/src/App.svelte (D is the A + C mix). They are standalone mockups: open each file directly, no build needed. The app itself is unchanged. "Reet" is Yorkshire for "really/very", so the copy has a light Yorkshire touch (easy to dial up or down), and the header uses the new brand logo.

  • D · A + C (your pick)

    Shelf

    A's editorial look with C's pipeline as sections: In use, To test, On the shelf. Move skills along with one button, Liked is a filter.

    Best for:
    the direction chosen so far
    Trade-off:
    sections replace the old tabs
  • A · Evolve

    Editorial

    Keeps the warm identity and the list. Adds a serif voice, a sticky filter bar, an "in use" rail on each entry and quieter secondary actions.

    Best for:
    a low-risk upgrade of today's layout
    Trade-off:
    still one long scrolling list
  • B · Dense

    Console

    A compact table for a large shelf, with keyboard shortcuts (j k l s u /) and counts always visible.

    Best for:
    power users with 50+ skills
    Trade-off:
    less friendly to casual browsing
  • C · Rethink

    Board

    Turns Save / In use into a pipeline: On the shelf → Saved to try → In use. Likes become a filter instead of a tab.

    Best for:
    seeing what you meant to try
    Trade-off:
    changes the mental model (tabs → columns)
