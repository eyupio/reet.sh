# reet.sh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build reet.sh, a self-hosted single-binary app to like, bookmark and mark as used the skills listed on skills.sh, shipped as a GHCR image with an image-only compose file.

**Architecture:** Go stdlib HTTP server with SQLite (`modernc.org/sqlite`), an embedded Svelte 5 SPA, and a `reet scan` subcommand that imports installed skills. Small internal packages (`ref`, `meta`, `store`, `api`, `scan`) each testable alone.

**Tech Stack:** Go 1.24, `net/http` mux, `modernc.org/sqlite`, Svelte 5 + Vite + TypeScript, Docker, GitHub Actions, GHCR.

**Spec:** `docs/superpowers/specs/2026-10-21-reet-sh-design.md`

## Global Constraints

- Go module path `github.com/eyupio/reet.sh`; binary name `reet`; subcommands `serve` and `scan`.
- No CGO; no web framework; SQLite driver `modernc.org/sqlite`.
- Env vars: `REET_TOKEN` (optional auth), `SKILLS_SH_TOKEN` (optional official API), `REET_DATA_DIR` (default `./data`, `/data` in Docker), `REET_ADDR` (default `:8080`).
- skill id formats: `owner/repo/skill` (github), `domain/skill` (well-known, page URL `/site/<domain>/<skill>`), `local/<name>` (unresolved).
- Outbound fetch timeout 8 seconds; metadata failure never blocks saving.
- Image: `ghcr.io/eyupio/reet.sh`, tags `latest`, `vX.Y.Z`, `sha-<short>`, platforms `linux/amd64,linux/arm64`, non-root.
- `docker-compose.yml` uses `image:` only, never `build:`.
- No dog or Zoomies-specific wording; plain terms in docs.

## Review Focus

- A skills.sh URL with trailing slash, query string, hash or a `/security/socket` suffix resolves to the same id as the bare slug.
- A non-skills.sh URL (for example a github.com link) returns 400 and saves nothing.
- Re-importing a skill (scan or paste) never resets existing `liked` or `bookmarked` flags or notes.
- skills.sh unreachable or returning garbage: add still succeeds and the skill shows its slug as name.
- With `REET_TOKEN` set, `/api/*` and `/quick` return 401 without the token; `/quick` accepts it as `?t=`; `/healthz` stays open.
