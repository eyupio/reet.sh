# Roadmap

What is planned but not shipped yet. Everything else described on the landing page is available today.

These are directions, not commitments: there are no dates.

Next, in this order:

- **Copy and paste in sessions, images included.** Paste text without a review step where the agent already guards against it, paste or drop an image into a session (kept in a private folder for that session on its machine, removed after a day), and copy an agent's own copy actions to your clipboard right after you ask for them.
- **Agent models from the machine.** The model list read from the machine where the agent can say it (OpenCode first), favourites, a default for sessions outside a project and per-project defaults for agent, model and effort, everywhere a session is started.
- **Structured sessions (Program 2).** A chat view over the agent protocol with approval cards (Allow once or Deny), starting with OpenCode in workspaces you trust. Terminal sessions stay as they are.

Later:

- **YOLO sessions.** Off by default, per session, audited, and refused by machines that turn it off. The launch bar shows it disabled until then.
- **Needs you.** Sessions that wait for you, counted on the bell. Home shows an honest empty state until then.
- **Agent installation, updates and removal.** Install, update and remove AI agents on connected machines from reet.sh. Today reet.sh works with the agents already installed on each machine.
- **Richer run orchestration.** More control over agent runs than opening a terminal session and continuing it later.
- **Fleet-wide agent configuration.** Configure agents across the whole fleet from one place. Today skills and setups are synced and restored per machine, with a reviewed plan before anything changes.

Shipped changes are listed in the repository's merged pull requests.
